I built and deployed an AI-powered compliance automation workflow for eXp Realty, helping automate a complex listing compliance process across multiple regions.

The system combines deterministic workflow orchestration with agentic AI, using agentic flows to analyze listing documentation and perform region-specific compliance checks.

What I built

Automated ingestion and processing of listing data from Google Sheets

Integration with SkySlope to retrieve listing and checklist documents

Agentic AI flows to analyze supporting documents and perform compliance checks

Automated validation of mandatory documentation

Conditional routing based on listing status, region, and compliance results

Human-in-the-loop QA for cases requiring review

Automated operational task creation and follow-up workflows

Persistent status and reviewer updates back into the operational data source

Retry and outreach logic to handle listings requiring subsequent action

The goal wasn't simply to add AI to an existing process. It was to build a reliable agentic system around a real business workflow, combining AI decision-making with deterministic controls and human oversight.
